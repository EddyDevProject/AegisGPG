Inspection report

          
Private by design, honest about limits

          
The cryptography runs in Rust on Sequoia-PGP and speaks standard OpenPGP, so your keys and files stay compatible with the tools you already have.

        


        

          
    
            
  • Least privilege
    The app window has no filesystem access. Only files you pick or drop are opened.
    • 
            
  • Secrets wiped from memory
    Passphrases and key material live in buffers that are zeroed when released.
    • 
            
  • Downloads treated as hostile
    Keys from servers lose any secret material, are size-capped and fetched over HTTPS only.
    • 
            
  • Private by default
    Keys and settings stay on your device, with owner-only file permissions.
    • 
            
  • Signed updates
    Every update is verified against a public key built into the app.
    • 
          


          

            
Known limits

            
AegisGPG has not been independently audited, and Sequoia flags its pure-Rust crypto backend as experimental.

            
For high-stakes use, read the code and prefer a hardware token.

Your system will warn you the first time you open AegisGPG. On macOS, open System Settings, Privacy & Security, then choose Open Anyway. On Windows, choose More info, then Run anyway.

Questions

          
Before you ask

        

        

          
Do I need GnuPG installed?
No. AegisGPG runs the cryptography itself, in Rust, on the Sequoia-PGP library. There is nothing to install besides the app.

          
Are my keys and files compatible with GnuPG, Thunderbird and Proton?
Yes. AegisGPG speaks standard OpenPGP, so keys and encrypted files work with GnuPG, Thunderbird, Proton and other OpenPGP tools.

          
Has it been audited?
No. It has not been independently audited, and Sequoia flags its pure-Rust crypto backend as experimental. For high-stakes use, read the code and prefer a hardware token.

          
Why does my system warn me when I open it?
The builds are not code-signed yet. On macOS choose Open Anyway in Privacy & Security; on Windows choose More info, then Run anyway.

          
Where are my keys stored?
On your device only, in the app data folder, with owner-only file permissions. Secret keys are only protected if you set a passphrase, and the app warns you if you skip it.

          
Is it free?
Yes. It is free and open source under the GPL-3.0-or-later license.
